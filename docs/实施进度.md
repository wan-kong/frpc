## 当前实现

- 入口已从 WebView 示例迁移到 MyGo 0.7.4 Native UI；前端示例、Vite、TypeScript 和 npm 配置已移除，保留固定版本 Go tool。
- 主窗口包括连接分组、隧道/访问者表格、搜索、排序、多选、检查器、日志，以及连接和协议表单。使用系统标题栏、菜单、文件面板、主题、字体、Keychain 和登录项。
- 支持多个独立 frpc 进程；官方 0.72.0 两架构保底内核以压缩资源存储，解压时核验固定 SHA-256，产品资源不含 frps。
- 已实现 TCP/UDP/HTTP/HTTPS/STCP/SUDP/XTCP 和访问者配置、批量端口预览、本地 TCP 监听端口选择、单条/批量启停、跨连接移动与删除。
- 保存和应用分离；元信息修改不重启连接，代理变更重载，公共参数或内核变化重启，初始化失败恢复旧实例。应用版本、内核版本和配置版本分别管理。
- 看护进程使用父子管道、真实子进程握手和管理 API 启动就绪检查；异常退出有退避和熔断。所有权记录绑定随机配置路径与进程启动时间，发现残留进程时阻止重复启动并提示处理。
- 状态区分进程、代理注册与业务可达；认证失败和重连日志适配仅对已适配内核生效，管理 API 正常响应不会覆盖认证失败。
- 数据采用原子 JSON 写入，保存前保留旧版本快照。凭证和 metadata 值使用 Keychain 引用；原文配置使用 AES-GCM 加密。
- TOML 导入先预览；未知字段保留原文，不覆盖用户原文件。原文保存使用新的加密源版本，不覆盖上一份有效源文件。可视化配置可明确转换到原文模式，以选择未适配的现代内核。
- 提供脱敏 TOML/日志导出、口令加密备份、恢复预览、配置回收区、快照恢复窗口和启动时凭证引用清理。
- 内核页面支持官方版本列表、下载、摘要/架构检查、自定义内核、默认版本选择和引用保护；下载可取消，下载任务不阻塞连接控制。
- GitHub Release 更新复用 MyGo 的签名引擎，由本项目 Native UI 面板提供检查、跳过、稍后、下载、取消和受控重启。重启恢复记录只消费一次。
- CLI check 脚本与 macOS CI 工作流已加入；没有执行打包、发布、提交或推送。

真实内核检查使用临时目录、loopback 地址和动态端口。测试 frps 仅位于忽略目录 `.test-tools/`，不成为产品功能。

## 与原方案的有据调整

1. MyGo 自带 Native updater 插件没有暴露本产品所需的重启协调钩子，因此复用 `mygo.Updater` 引擎，自行实现纯 Native UI 更新面板。没有引入 WebView 或另一套更新签名机制。
2. 保底 frpc 以 gzip 资源保存，避免发行签名流程修改 Mach-O 后使固定摘要失效；运行时从受应用资源签名保护的压缩文件解压并核验原始官方内核。
3. 残留进程默认阻止重复启动。连接设置提供身份审查；明确展示 PID、启动时间、受管内核和配置后，用户可选择停止/强制终止，执行前复核记录摘要与身份。身份不明不发送信号，不按名称或旧 PID 批量杀进程。
4. 快照仍引用的凭证会保留到最后一个有效引用消失，避免回收区到期后破坏保留的快照；配置回收区在启动时执行七天期限清理。

## 本轮完成的本地收尾

- 表单以 fingerprint 判断实际修改，支持会话草稿保留、恢复、放弃；新建菜单不会覆盖已打开草稿，退出仅对实际未保存内容提示。
- 保存成功后应用失败，同步已保存 revision 与凭证引用；保存期间继续输入不丢失。内核回退时保留未成功应用的选择为修改，隧道表单同步回退后的最新 revision。
- 删除条目已保存、随后应用失败时关闭已失效的编辑器，主窗口保留错误和待应用提示；批量端口保存要求预览与当前输入一致。
- 新增残留进程审查和处理入口，真实隔离 frpc 检查身份匹配、记录改变拒绝、外部 PID 拒绝、受管进程拒绝与准确清理。补齐 kill(0) 与 ps 之间进程被回收的退出复核；相关四项 race 用例连续十轮通过。
- 自动重启使用真正五分钟滑动窗口；旧 generation/手动停止后的退出事件不计入当前轮次，也不覆盖当前错误。
- 主窗口明确展示等待状态、部分注册成功、注册失败与待应用，不把配置接受等同于业务可达。
- 官方下载先在临时目录验证，随后原子入库；取消或校验失败不覆盖既有内核，同版本不同摘要拒绝替换。
- 内核删除会清理准确受管文件，保护默认、连接、回收区、快照、运行实例、自动重启等待及残留进程引用；拒绝符号链接路径，保留同目录无关文件。内部启动读锁与删除写锁互斥。
- 核心修改命令统一补充结构化失败分类，保留下层具体错误、字段与 cause；取消、超时、权限和本机端口冲突按明确事实分类。
- 恢复窗口异步读取快照，确认后恢复同一份预览对象并保留原文件，避免预览和实际恢复选择不同快照。
- 增加两架构 gzip SHA-256/Mach-O 检查、并发更新偏好持久化、异步输入保存和 UI race 检查。
- 隧道开关按 250ms 合并，期望状态即时显示为待应用；冲突时恢复持久化状态，不丢其他已保存修改。退出取消尚未提交的队列。
- 日志搜索 150ms 防抖，稳定帧复用筛选结果；后台更新提示不会在编辑器上自动叠加弹层。
- 连接/隧道凭证读取与编辑器开启合并到同一完成投递；凭证、metadata 和 dirty baseline 一起发布，避免分散回调。
- 界面任务统一绑定窗口生命周期。真正销毁窗口时取消命令、内核和更新任务，已排队的旧回调不再修改状态；隐藏窗口保留草稿和进程，并在再次显示时刷新快照。
- 新增 CLI Tester 焦点循环、关闭后返回触发控件、中文组合输入确认、嵌套弹层 Esc、窗口销毁后的取消和旧回调拒绝检查。上述证据不等同于真实系统输入法/VoiceOver 验收。
- 补齐 Esc 先关闭最上层弹层、再清除搜索；窗口级新建/检查器快捷键在表单中不抢占输入。
- 管理端口竞争后最多重新选择并严格验证三次；仅对认证内核当前可视化启动的本机管理端口进行重试，原文模式不改端口、不重试。预检查和真实启动报错共同识别竞争，早期失败的临时运行配置会清理。
- 管理 API 观察频率按当前可见连接 2 秒、其余连接 5 秒、全部窗口隐藏 10 秒切换；设置窗口可见时仍保持后台频率。每连接仅一个串行观察循环，停止/旧 generation/旧 revision/取消后的请求不再写入当前状态。
- 启动、应用及重连成功后建立 15 秒观察期限；单次通知使安静界面也能更新超时文案。未决条目继续观察，晚到的成功可恢复显示，不撤销已注册隧道；明确注册错误优先显示原因，超过 10 秒的旧 API 结果标为过期。
- 新增虚拟时钟检查，覆盖观察频率切换、同一 scope 不重置计时、旧请求结果丢弃、观察期限替换/取消、15 秒超时与成功/失败优先级；真实 frpc 检查覆盖三次重新选端口、次数耗尽和原文端口不变。
- 侧栏复用 MyGo Split，初始 220 DIP，拖动和键盘调整限制在 190–300；检查器统一为 300 DIP。日志复用垂直 Split，初始 220 DIP，可拖动或键盘调整，关闭重开及窗口改变后保留偏好高度，空间不足时限制显示高度。
- 日志分栏使用实际内容区尺寸，表格和日志共用可用高度；布局输入变化仅请求一次测量后续帧，没有空闲重建循环。CLI Tester 覆盖拖动、键盘、900/1120/1440 宽度、600 高度、明暗和 125% 缩放。
- 原文模式也可打开可调整的日志面板；已修复原文页面提前返回导致日志开关无效的问题，仍不提供单隧道开关或可视化热重载。
- 首次关闭主窗口显示后台运行说明，随后异步记录确认标记；后续关闭直接隐藏。保留草稿和执行中的命令，不占用连接控制 Busy，偏好写入失败仍允许隐藏；旧设置表单不会覆盖标记。CLI 检查覆盖重复关闭、重启读取、并发旧设置和失败降级。

## 发行所需输入和未验证项

当前 `mygo.json` 仍使用开发身份，没有正式 GitHub 仓库或更新公钥，开发模式的 updater 会明确显示不可自更新。

正式发行需要项目所有者提供或确定：

- GitHub 发布仓库 `owner/repo` 与最终 Bundle ID。
- 更新签名公钥及妥善保存的私钥。

`scripts/configure-release.py` 可验证或根据明确提供的环境变量写入公开发行配置，不打包、不签名、不发布。未具备这些输入时，不创建假 feed、不生成假签名资产、不声称已完成 GitHub Release 升级闭环。
